# Milk-V Duo(SG2000) 手势/手部检测 + RTSP 推流实现指南

> 里程碑文档：记录了在评估板上实现「摄像头采集 → yolov8 手部检测 → 画框 → H.264 编码 → RTSP 推流」的**完整可复现路径**。
> 硬件：Milk-V Duo S（SG2000, RISC-V CV181x），固件 `milkv-duos-musl-riscv64-sd_v2.0.1`，GC2083 MIPI 摄像头。
> 验证日期：2026-08-05，验证记录见 `SG2000手势识别验证日志.md`（#19/#22/#24）。

---

## 1. 背景与关键结论（为什么这样做）

**踩过的死路（不要重复）**：
- `CVI_TDL_HandClassification` → 恒返回 `0xC0010109`（VPSS_GET_FRAME），**固件样例不过是不检查返回值**（objdump 确认 0x11070 后不读 a0）。死路。
- `CVI_TDL_Image_Classification` + `HANDCLASSIFICATION` 模型 → `0xC001010B`（NOT_YET_INITIALIZED）。死路。
- 用 duo-tdl-examples 头文件（`SAMPLE_VI_INFO_S=152`）编译 → 与固件底层库（`SAMPLE_VI_INFO_S=156`）**ABI 错位**，VI 初始化报 `0xffffffff` / `s32WorkingViNum<=0`。**根因：头文件版本不匹配固件**。

**正确路径（本指南）**：
1. **头文件**：用 `milkv-duo/duo-buildroot-sdk-v2`（固件配套 SDK）的 `cvi_mpi/include` 头文件 + `sample/common/sample_common_*.c`。其 `SAMPLE_VI_INFO_S=156`、`SAMPLE_VI_CONFIG_S=808`、`SAMPLE_INI_CFG_S=232`，与固件反汇编**完全匹配**。
2. **运行时库**：用**固件自带** `/mnt/system/lib`、`/mnt/system/usr/lib`、`/mnt/system/usr/lib/3rd`，特别是固件 `libsample.so`（174KB，编译自 duo-buildroot-sdk-v2）。
3. **推理 API**：手部检测用 **`CVI_TDL_Detection(handle, &frame, CVI_TDL_SUPPORTED_MODEL_HAND_DETECTION, &obj)`**（固件真实验证的通道）。训练架构 yolov8。

## 3. 编译

### 编译 middleware（VI/VPSS/RTSP 初始化，用 dbr2 头文件）
```bash
CC=/home/oooa/Milk-V-Duo/ai/host-tools/gcc/riscv64-linux-musl-x86_64/bin/riscv64-unknown-linux-musl-gcc
BASE="-mcpu=c906fdv -march=rv64imafdcv0p7xthead -mcmodel=medany -mabi=lp64d -DCV181X -D__CV181X__ \
      -D_LARGEFILE_SOURCE -D_LARGEFILE64_SOURCE -D_FILE_OFFSET_BITS=64"
INC="-I dbr2_inc -I dbr2_inc/linux -I dbr2_inc/isp/cv181x -I dbr2_mw \
     -I ai/duo-tdl-examples/include/tdl -I ai/duo-tdl-examples/include/system \
     -I ai/duo-tdl-examples/include/tdl/core/utils -I ai/duo-tdl-examples/common"
# 注意：dbr2_inc 的 sample_comm.h 结构体与固件匹配(156)，ai/duo-tdl-examples/include 仅用于 trio 特有头文件(vpss_helper/rtsp/vi_vo_utils)
$CC $BASE $INC -c ai/duo-tdl-examples/common/middleware_utils.c -o /tmp/mw.o
$CC $BASE $INC -c ai/duo-tdl-examples/common/sample_utils.c   -o /tmp/su.o
```

### 编译应用（sample_vi_gesture_rtsp）
源码见 `sample_vi_gesture_rtsp.c`（基于 trio `sample_vi_hand.c`，修正推理 API）。核心推理调用：
```c
CVI_TDL_OpenModel(handle, CVI_TDL_SUPPORTED_MODEL_HAND_DETECTION, model_path); // 手部检测模型
CVI_TDL_SetModelThreshold(handle, CVI_TDL_SUPPORTED_MODEL_HAND_DETECTION, 0.3);
// 每帧：
CVI_TDL_Detection(handle, &frame, CVI_TDL_SUPPORTED_MODEL_HAND_DETECTION, &obj);
```
```bash
$CC $BASE $INC -c sample_vi_gesture_rtsp.c -o /tmp/svg_rtsp.o
```

### 链接（关键：固件库 + atomic_shim）
```bash
$CC $BASE -o /tmp/sample_vi_gesture_rtsp /tmp/svg_rtsp.o /tmp/mw.o /tmp/su.o atomic_shim.so \
  -Wl,--allow-shlib-undefined -L/tmp/boardlib/sys -L/tmp/boardlib/tpu \
  -lcvi_tdl -lcvi_rtsp -lsample -lsys -lvi -lvo -lvpss -lgdc -lrgn -lini -lsns_full -lisp \
  -lvdec -lvenc -lawb -lae -laf -lcvi_bin_isp -lcvi_bin -lmisc -lisp_algo \
  -lcvikernel -lcvimath -lcviruntime -lcnpy -lz -lopencv_core -lopencv_imgproc -lopencv_imgcodecs \
  -lm -lrt -latomic -lpthread
```
- `atomic_shim.so`（导出 `__sync_fetch_and_add_1`/`__sync_fetch_and_and_1`/`__atomic_compare_exchange_1`）解决 C906 无 A 扩展 + musl 下固件库的 hidden atomic 依赖，`-latomic` 需放链接命令后段。
- `-L/tmp/boardlib/sys`（固件 `/mnt/system/usr/lib` 拉回的库）、`/tmp/boardlib/tpu`（`/mnt/system/lib` TDL/TPU 库）。运行时实际从板上 `/mnt/system/*` 加载。

## 5. 关键源码配置（VPSS/VBPool，务必与固件匹配）

在 `sample_vi_gesture_rtsp.c` 的 `main` 中：
```c
SIZE_S stVencSize = {.u32Width = 1280, .u32Height = 720};   // 编码输出
// VBPool[0] → VPSS Grp0 Chn0（编码）：尺寸必须 = VPSS Chn0 输出(1280x720)，否则 Chn0 取帧 0xc006800e
astVBPoolSetup[0] = { .enFormat=VI_PIXEL_FORMAT, .u32BlkCount=4,
                      .u32Width=1280, .u32Height=720, .bBind=true,
                      .u32VpssChnBinding=VPSS_CHN0, .u32VpssGrpBinding=0 };
// VBPool[1] → Grp0 Chn1（推理）：1280x720
// VBPool[2] → TDL 预处理：BGR888_PLANAR 1280x720
VPSS_GRP_DEFAULT_HELPER2(&vpssAttr, sensorW, sensorH, VI_PIXEL_FORMAT, 1); // device 1，双模式3路输出
VPSS_CHN_DEFAULT_HELPER(&chnAttr[0], 1280, 720, VI_PIXEL_FORMAT, true);
VPSS_CHN_DEFAULT_HELPER(&chnAttr[1], 1280, 720, VI_PIXEL_FORMAT, true);
```

**两个关键修复（反复踩坑）**：
1. **VBPool[0] 尺寸**必须等于 VPSS Chn0 输出尺寸（1280×720），否则 `CVI_VPSS_GetChnFrame(0, Chn0)` 报 `0xc006800e`。
2. **VENC 线程失败处理**：`DrawRect`/`SendFrame` 单次失败不要 `bExit=true`（会整体退出），改为 `continue`/`usleep` 重试。

## 6. 工作区关键文件

| 文件 | 说明 |
|------|------|
| `sample_vi_gesture_rtsp.c` | 手部检测 + 画框 + RTSP 推流主程序（可复现） |
| `dbr2_inc/` `dbr2_mw/` | duo-buildroot-sdk-v2 头文件 + sample_common 源码（固件 ABI 匹配） |
| `atomic_shim.c` `atomic_shim.so` | C906 无 A 扩展的 atomic 软件实现 |
| `ai/models/yolov8n_det_hand_384_640_INT8_cv181x.cvimodel` | 手部检测模型（384×640 yolov8） |
| `SG2000手势识别验证日志.md` | 完整验证记录（#0-#24） |

**复现缺陷提示**：每次运行推流前若上/上次程序异常终止，VPSS Grp0 可能残留 `0xc0068004`，需 `reboot` 评估板。

## 7. 当前状态与下一步

**已完成**：摄像头 → VI/VPSS → yolov8 手部检测（`hand count` 0/1 实时切换）→ 画框 → H.264 → RTSP 推流，在 Fedora 上可看且看到手部画框。
