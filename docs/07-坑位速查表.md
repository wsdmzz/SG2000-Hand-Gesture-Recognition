# 07 - 坑位速查表（全部踩坑与解决方案）

> 本项目从旧固件到当前方案踩过的所有坑，按主题速查。**给复现者优先看这里**。

## 一、媒体/VI/VPSS 初始化

| 坑 | 症状 | 解决 |
|----|------|------|
| 头文件 ABI 错位 | `s32WorkingViNum<=0` / `0xffffffff` | 用固件配套 duo-buildroot-sdk-v2（dbr2_inc），SAMPLE_VI_CONFIG_S=808 |
| VBPool 尺寸不匹配 | VPSS Chn0 取帧 `0xc006800e` | VBPool[0] 尺寸必须 = VPSS Chn0 输出尺寸 |
| VPSS grp 残留 | `vpss grp0 occupied` / `0xc0068004` | 程序主动 `DestroyGrp`，或用前 `reboot` |
| sensor_cfg.ini 缺失 | 回退默认 IMX327 + 内核 Oops | 补全 GC2083 配置（bus3 i2c0x37 mipi0） |
| VENC 内核 Oops | 硬编码 MJPEG/H.264 崩溃 cv181x_vpss | 改 OpenCV 软编码（imencode） |

## 二、TDL API / 模型加载

| 坑 | 症状 | 解决 |
|----|------|------|
| HandClassification 死路 | 恒 `0xC0010109` | 放弃，样例不查返回值是假成功 |
| Image_Classification 死路 | 恒 `0xC001010B` | 依赖完整媒体框架 + FP32 bug，改用裸 cviruntime |
| OpenModel failed | `Net setup failed` | model_factory.json 声明自定义模型参数 |
| 7 类模型崩溃 | convertPixelFormat Abort | 改 `vpss_image.cpp` 兼容 FP32（docs/04） |
| TDL 恒输出固定类 | FP32 输入模型预处理无归一化 | 模型内置归一化 + 裸 cviruntime（docs/04） |
| TDL_Keypoint 恒坐标 | 输出不变 | 裸 cviruntime 推理 keypoint（docs/05） |

## 三、模型训练/转换（TPU-MLIR）

| 坑 | 症状 | 解决 |
|----|------|------|
| ONNX 外部权重错乱 | 转换后识别错 | 复制的 .onnx 必须与 .onnx.data 文件名匹配 |
| ReduceMean 转换失败 | ReduceMean/Conv kernel_shape 问题 | `fix_onnx_reducemean.py` |
| asymmetric 撞崩 | `AvgPool.cpp Assertion !asymmetric` | TPU-MLIR v1.28.1 缺陷，sym/BF16 替代 |
| 归一化不匹配 | 实机识别错 | 训练/推理归一化必须一致（x/127.5-1 或 x/255） |
| 模型输入恒 FP32 | 7类模型无法出 INT8 输入 | 库层兼容（docs/04）或关键点方案 |

## 四、网络 / SSH

| 坑 | 症状 | 解决 |
|----|------|------|
| USB 网络 No module | 误以为缺 gadget 模块 | 非缺模块，`echo device > /proc/cviusb/otg_role` |
| 无 SSH 服务端 | 新固件无 dropbear | 交叉编译 dropbear v2022.83（链接器匹配 v0p7_xthead） |
| scp 不可用 | dropbear 无 sftp-server | 用 `ssh 'cat > file' <` 管道传文件 |
| USB 网卡 IP 不稳定 | 掉线/路由表错 | 网线直连 192.168.50.1 最稳 |

## 五、交叉编译（C906 / musl）

| 坑 | 症状 | 解决 |
|----|------|------|
| ABI 错位 | 链接后运行崩溃 | 用 `-march=rv64imafdcv0p7xthead -mabi=lp64d` |
| atomic 缺失 | 固件库 undefined `__sync_*`/`__atomic_*` | `atomic_shim.so` + `-latomic` |
| 链接器名不匹配 | 动态库 not found | 链接器必须匹配 `ld-musl-riscv64v0p7_xthead.so.1` |
| C906 无 A 扩展 | 原子指令非法 | libatomic / atomic_shim |

## 六、推流

| 坑 | 症状 | 解决 |
|----|------|------|
| HTTP 长连接卡死 | 浏览器刷新后卡 | 独立线程 + poll 非阻塞 + 断线检测 |
| 一手多框 | 手指/手掌两个框竞争 | 手框 NMS 合并（docs/05） |
| 实时图像偏手势 | ROI 形态与训练图不符 | 关键点方案根治（docs/05） |

## 七、其他

| 坑 | 症状 | 解决 |
|----|------|------|
| SD 卡 rootfs 没写上 | dd 写普通文件 | 写分区节点（/dev/mmcblk0p3） |
| boot.sd 格式错 | 无法引导 | 必须 FIT 格式（kernel+fdt） |
| 环境变量 | 库找不到 | LD_LIBRARY_PATH 含 /mnt/system/lib:/usr/lib:/usr/lib/3rd |

## 错误码速查

| 错误码 | 含义 | 触发场景 |
|--------|------|----------|
| `0xC0010109` | VPSS_GET_FRAME | HandClassification 死路 |
| `0xC001010B` | NOT_YET_INITIALIZED | Image_Classification 无框架初始化 |
| `0xC0010102` | open fail | 模型无法打开 |
| `0xc0068004` | VPSS grp occupied | VPSS 残留 |
| `0xc006800e` | CHN_GET_FRAME | VBPool 尺寸不匹配 |
| `0xffffffff` | 通用失败 | ABI 错位导致 VI 初始化失败 |
